# pcic chaos rubric

Fault injection for `SPEC.md`. The question in every case: does pcic stay safe (no send it should not make, no interrupted owner turn, no lost owner prompt, no repeated job) and say what happened? Each case names its injection, the expected safe behaviour and the pass check.

Where: cases marked **T** run in the Tier T harness ($0, fake clock and recorded payloads). Cases marked **E** run on the Tier E isolated daemon (paid, owner approval, same budget rules as `E2E-RUBRIC.md`). Some run in both. Invariants N1 to N5 from `E2E-RUBRIC.md` apply to every case.

Universal safe behaviour (checked in every case):

- S1: no `/compact` after an aborted or failed checkpoint.
- S2: no pcic send while the agent has an active turn.
- S3: no owner prompt lost (it either ran or is visible in the chat with the guard message).
- S4: at most one job per (agent, anchor).
- S5: the plugin process is still alive and handles the next agent normally.

## Pass rule

A chaos run passes when every case meets its Pass column and S1 to S5. A case that needs a live fault (C9 and C10 stub, C15) and could not be set up is reported as skipped, not passed.
